# Capture the Flag (CTF)

## Overview

This section contains CTF competition writeups, challenge solutions, and notes. CTF competitions are a practical way to develop and test cybersecurity skills across multiple domains.

---

## Competitions

### National Cyber League (NCL)

The NCL is a biannual cybersecurity competition for students, featuring challenges across multiple categories.

| Phase | Description | Link |
|-------|-------------|------|
| Gym | Pre-season practice challenges | [Gym Writeups](./NCL/Gym/README.md) |
| Individual | Solo competition game | [Individual Writeups](./NCL/Individual/README.md) |
| Team | Team-based competition game | [Team Writeups](./NCL/TEAM/README.md) |

### Other Platforms

- **TryHackMe** -- Guided rooms and challenges
- **HackTheBox** -- Machine and challenge-based labs
- **PicoCTF** -- Beginner-friendly CTF challenges
- **OverTheWire** -- Wargames for learning Linux and security basics

---

## Challenge Categories

| Category | Skills Tested |
|----------|--------------|
| **OSINT** | Open source intelligence gathering |
| **Cryptography** | Ciphers, encoding, hashing, RSA |
| **Web Exploitation** | SQL injection, XSS, SSRF, auth bypass |
| **Forensics** | Disk images, memory dumps, packet captures, steganography |
| **Reverse Engineering** | Binary analysis, disassembly, debugging |
| **Binary Exploitation** | Buffer overflows, format strings, ROP chains |
| **Network Traffic** | Packet analysis, protocol reconstruction |
| **Log Analysis** | SIEM, event correlation, anomaly detection |
| **Enumeration** | Service discovery, password cracking |

## Writeup Template

When documenting a CTF challenge, use this structure:

```markdown
## Challenge Name
**Category:** [e.g., Cryptography]
**Points:** [e.g., 200]
**Difficulty:** [Easy/Medium/Hard]

### Description
[Challenge prompt or description]

### Approach
[Step-by-step methodology]

### Solution
[Commands, scripts, or techniques used]

### Flag
`flag{example_flag_here}`

### Lessons Learned
[What you learned from this challenge]
```
