## Setting Up a Lab Environment

### Recommended Virtualization
- **VMware Workstation** or **VirtualBox** for local VMs
- **Proxmox** for dedicated lab servers
- **Docker** for lightweight, disposable environments

### Vulnerable Targets
- [Metasploitable 2/3](https://sourceforge.net/projects/metasploitable/)
- [DVWA](https://github.com/digininja/DVWA)
- [VulnHub](https://www.vulnhub.com/) -- Downloadable vulnerable VMs
- [HackTheBox](https://www.hackthebox.com/) -- Online lab environment
- [TryHackMe](https://tryhackme.com/) -- Guided online labs

### Network Isolation
- Use host-only or NAT networks to isolate lab traffic
- Never expose vulnerable VMs to the internet
- Snapshot VMs before testing for easy rollback
